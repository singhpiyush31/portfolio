# Piyush Singh | Portfolio

My personal portfolio, built with plain HTML, CSS and JavaScript.

## Features

- Smooth scrolling and animated section transitions
- A spider cursor effect, written from scratch on a canvas
- Project details view, with content loaded from one data file
- Responsive layout that respects the reduced-motion setting

## Run locally

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.

## Edit the content

All the text, projects and links are in `data.js`.
